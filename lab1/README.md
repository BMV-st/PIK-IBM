## Задание

Разработать программы для решения биквадратного уравнения.

Программы должны быть разработаны в виде консольного приложения на языке Python. Разработайте **три программы** на языке Python:

Программа осуществляет ввод с клавиатуры коэффициентов **А, В, С**, вычисляет дискриминант и **ДЕЙСТВИТЕЛЬНЫЕ** корни уравнения (в зависимости от дискриминанта).

Коэффициенты А, В, С могут быть заданы в виде параметров командной строки (вариант задания параметров приведен с примером кода). Если они не заданы, то вводятся с клавиатуры в соответствии с пунктом 2. Описание работы с параметрами командной строки.

Если коэффициент А, В, С введен или задан в командной строке некорректно, то необходимо проигнорировать некорректное значение и вводить коэффициент повторно, пока коэффициент не будет введен корректно. Корректно заданный коэффициент — это коэффициент, значение которого может быть без ошибок преобразовано в действительное число.

## Описание работы с параметрами командной строки

Параметры командной строки передаются в программу через список `sys.argv`. Первый элемент списка (`sys.argv[0]`) — имя самого скрипта, последующие элементы — переданные аргументы.

**Пример запуска с параметрами:**

```bash
python script.py 1 -5 4
```

В этом случае:

- `sys.argv[0]` = `"script.py"`
- `sys.argv[1]` = `"1"` — коэффициент A
- `sys.argv[2]` = `"-5"` — коэффициент B
- `sys.argv[3]` = `"4"` — коэффициент C

**Правила обработки:**

| Ситуация | Поведение программы |
|---|---|
| Все три параметра заданы и корректны | Коэффициенты берутся из командной строки |
| Часть параметров отсутствует | Отсутствующие вводятся с клавиатуры |
| Параметр задан некорректно | Значение игнорируется, коэффициент запрашивается повторно |
| Параметры не заданы вовсе | Все коэффициенты вводятся с клавиатуры |

**Пример кода для разбора параметров командной строки:**

```python
import sys

def parse_args(argv):
    """
    Извлекает коэффициенты A, B, C из параметров командной строки.
    Возвращает список [a, b, c]; отсутствующие/некорректные = None.
    """
    result = [None, None, None]
    for i, arg in enumerate(argv[1:4]):
        try:
            result[i] = float(arg)
        except ValueError:
            result[i] = None  # некорректное значение игнорируем
    return result


if __name__ == "__main__":
    a, b, c = parse_args(sys.argv)
    print(f"A = {a}, B = {b}, C = {c}")
```
